# AI多言語インタビューツール(Gemini API版)

日本の伝統文化に対する海外の人の反応を調べるための、AIインタビューツールです。
管理者が資料を入れるだけで、Gemini が回答者の言語で1問ずつ質問し、答えに合わせてその場で次の質問を作ります。

## 画面は2つ

| 画面 | URL | 使う人 |
|---|---|---|
| 管理者画面 | `/admin` | 調査する人(パスワードでログイン) |
| 回答者画面 | `/i/<調査ID>` | 海外の回答者(ログイン不要。リンクを送るだけ) |

### 管理者画面でできること
- **資料からAIで設定を作る**: 資料を入れて「AIで作る」を押すと、調査目的・質問リスト・回答者向け案内文をGeminiが作ります
- 調査を作る: 調査目的・必ず聞きたいテーマ・AIへの指示・質問数の上限・選べる言語
- **質問リスト**: 順番つきの質問、深掘りの指示、選択肢ボタン(例: とても興味がある / やや… / どちらとも言えない)。AIはこの順で聞き、答えに応じて深掘りします
- 資料を入れる: PDF・画像・テキスト・音声・動画(何語でもOK)。「回答者に見せる」をオンにすると、AIが話の流れで資料を見せて感想を聞きます
- 回答一覧: 原文と日本語訳を並べて表示。完了時に**AIレポート**(反応の良し悪し・関心度・回答者タイプ・主な意見・印象的な発言)を自動作成
- **統計・検索**: 回答者数・完了率・平均関心度・満足度、言語/国/年齢/反応の分布、質問ごとの到達状況、原文と日本語訳の全文検索
- AI全体分析: 全回答を横断して、反応のパターン・国ごとの違い・障壁・示唆を日本語レポートに
- **テスト(AI模擬回答)**: 架空の回答者(ペルソナ)をAIが演じて最後まで回答し、質問の流れを本番前に確認できます(統計には含めません)
- 書き出し: CSV(全発言 / 回答者ごとのレポート一覧)、JSON

### 回答者画面
- ブラウザの言語から自動で言語を選択(変更可)。22言語に対応、一覧にない言語で書いてもAIが合わせます
- 国・年齢・性別・訪日経験を任意で入力
- チャット形式で1問ずつ。選択肢ボタンでも答えられ、マイクボタンで音声入力も可(Chrome・Safari)
- 最後に5段階でインタビューの満足度を評価
- 途中でページを閉じても、同じ端末なら続きから再開

## 使い方

1. Node.js 18 以上をインストール
2. Google AI Studio (https://aistudio.google.com/apikey) で Gemini APIキーを発行
3. このフォルダで `.env.example` を `.env` にコピーし、`GEMINI_API_KEY` と `ADMIN_PASSWORD` を記入
4. `npm start` で起動し、http://localhost:3000/admin を開く

APIキーはサーバーだけが持ち、回答者のブラウザには送られません。
APIキーなしで起動すると「デモモード」(AIの代わりに決まった文章を返す)になり、画面の動きだけ確認できます。

## 無料で公開する(Render + Supabase + Gemini 無料枠)

すべて無料プランで動きます。クレジットカードは不要です(2026年11月時点の各サービスの無料枠)。

1. **Gemini APIキー**: https://aistudio.google.com/apikey で「Create API key」
2. **Supabase**(データ保存用): https://supabase.com で無料プロジェクトを作成 → 左メニュー「SQL Editor」に `supabase.sql` の中身を貼って「Run」 → 「Project Settings → API Keys」で Project URL と secret key をコピー
3. **Render**(公開用): https://dashboard.render.com/blueprints → 「New Blueprint Instance」でこのリポジトリを選び、`GEMINI_API_KEY` `ADMIN_PASSWORD` `SUPABASE_URL` `SUPABASE_SECRET_KEY` を入力して「Apply」

数分で `https://ai-interview-xxxx.onrender.com` が発行されます。`/admin` が管理者画面です。

### 無料プランの注意
- **Render無料プラン**: 15分アクセスがないと休止し、次に開くとき30〜60秒ほど待ちます。回答者にリンクを送る前に、一度自分で開いて起こしておくと安心です。再起動してもデータはSupabaseから復元されます
- **Supabase無料プラン**: 1週間アクセスがないとプロジェクトが一時停止します(データは消えず、ダッシュボードから再開できます)。容量は500MBまで
- **Gemini無料枠**: 1分あたり・1日あたりの回数制限があります。上限に当たると回答者側にエラーが出るので、大人数に一斉配信するときは有料枠への切り替えか、`GEMINI_MODEL=gemini-2.5-flash-lite`(無料枠の回数が多め)を検討してください。また、無料枠では入力内容がGoogleのサービス改善に使われることがあるため、回答者向け案内文でその旨を伝えるのが安全です

## データの保存場所
`SUPABASE_URL` と `SUPABASE_SECRET_KEY` を設定すると、下のファイルが Supabase の `app_files` テーブルにも保存され、起動時に復元されます。設定しなければローカルのみです。
- `data/studies/` 調査の設定
- `data/files/` アップロードした資料
- `data/sessions/<調査ID>/` 回答(原文・日本語訳・AI要約)

## AIの質問の仕方
プロンプトに定性調査のインタビュー技法を組み込んでいます: 答えやすい質問から始める(ラポール形成)、広い→狭いの順、抽象と具体の往復、「なぜ?」を連発しない、感情の受け止め、仮定の質問、逆側の視点、矛盾の穏やかな確認、中間要約、段階的な選択肢。これらは「みらい議会」の公開ドキュメントにある考え方を参考にして、このツール用に書き直したものです(みらい議会のソースコードは含みません)。

## 注意
- 費用対策として、Geminiの呼び出しは1日 `DAILY_AI_CALL_LIMIT` 回(初期値3000)まで、1人の回答者は質問数上限の2倍+5回までに制限しています
- 資料は質問のたびに Gemini に送られます。大きなPDFや動画が多いとAPI料金と応答時間が増えるので、要点をまとめた資料がおすすめです(合計30MB程度まで)
- 回答者に名前や連絡先は聞かない設計です。調査の同意文は回答者向け案内文に書いてください
